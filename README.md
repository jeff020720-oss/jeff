# 국제통상 최종보고서

아주대학교 국제통상 연구회

## 포함 파일

- 국제통상_최종보고서.docx — 본문 11pt, 편집 가능한 표·그림, 본문에 연결된 실제 Word 각주 25개
- 국제통상_최종보고서.pdf — 같은 Word에서 변환한 열람·인쇄용 파일

도현우 작성 내용을 수입·유통 구조와 이론적 배경에 통합하고, 심수민·박연희의 사례와 실제 추진 내용을 연결했습니다. 기존 사진자료를 유지하며 자간·서체·문단 정렬을 정리했습니다.

## 카카오톡으로 전달하기

1. 이 ZIP을 먼저 파일 앱/내 파일/다운로드 폴더에 저장합니다.
2. 압축을 풀어 위의 .docx 또는 .pdf 파일을 선택합니다.
3. 카카오톡의 파일 첨부 기능으로 저장된 파일을 보냅니다.

브라우저 미리보기에서 곧바로 공유하면 앱에 따라 임시 캐시 파일 이름이 전달될 수 있습니다. 압축 안의 실제 파일은 .docx/.pdf 확장자로 저장되어 있습니다.
