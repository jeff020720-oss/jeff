## 구성

아주대학교 표지, 흑백 표 21개, 기존 시각자료 57개, 각주 12개와 참고문헌을 포함한 52쪽 보고서입니다. 기존 메인 보고서와 두 추가 파트의 자료를 통합하고, 예약결제와 실제 수입 실행을 구분하여 분석했습니다.

선행연구 4편은 공개 재현자료에 보존된 초록·서지를 확인한 범위에서 인용했습니다. 원문 전문 미열람과 비용 분석의 가정·한계는 보고서에 명시했습니다.
