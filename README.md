# 국제통상 연구보고서

**아주대학교 국제통상 연구회**

## 원문 보존·통합 수정본

기존 메인 보고서와 심수민·박연희 작성 부분의 문장·사례·표·사진을 유지하여 통합했습니다. 기존 장 구성을 복원하고, 선행연구 연결과 공급조건·자금·재고 분석을 추가했습니다. 예약결제 용어, 비용 계산 및 서로 충돌하는 일부 표현을 정리했습니다.

- [수정본 PDF](reports/ajou_trade_report_revised.pdf)
- [수정본 워드](reports/ajou_trade_report_revised.docx)

PDF는 원본의 페이지·사진 배치를 보존한 58쪽 제출용 파일입니다. 워드는 본문·표·사진을 편집할 수 있게 복원했으며 편집 흐름에 따라 쪽수가 다릅니다.

파일 페이지에서 **Download raw**를 선택하면 내려받을 수 있습니다.
